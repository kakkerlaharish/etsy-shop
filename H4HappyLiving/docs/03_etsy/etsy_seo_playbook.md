# Etsy SEO Playbook

## Goal

Make each listing easy for the right shopper to understand and find.

## Keyword process

1. Start with the customer’s problem, product type, recipient, occasion, style, and format.
2. Gather real Etsy search phrases and competitor wording; record evidence in `research/keywords/`.
3. Choose one primary phrase that accurately describes the item.
4. Build related, natural long-tail phrases for the title, tags, attributes, and opening description.
5. Avoid irrelevant or misleading keywords.

## Listing essentials

- Write a specific, readable title led by the primary phrase.
- Use all 13 tag slots with distinct, relevant phrases where available.
- Select the most accurate category and complete relevant attributes.
- In the first description paragraph, plainly state the item, audience, format, and key benefit.
- Use clear images and mockups that show what the buyer receives.

## Review cadence

Revisit listings after enough impressions and visits to learn from. Change one meaningful element at a time and note the date and reason.
