# Product Naming Conventions

## Product folder names

Use a short, stable lowercase slug with hyphens:

- `family-meal-planner`
- `kids-morning-routine-chart`
- `weekly-wellness-journal`

Do not include temporary keywords, version numbers, marketplace names, dates, or brand-pillar names in the product folder name.

## Product identity

Assign each product a stable identifier in its README:

`H4-[PILLAR]-[NNN]`

Pillar codes:

- `ORG` — Organize
- `LRN` — Learn
- `CRT` — Create
- `THR` — Thrive

Example: `H4-ORG-001` for the first Organize product. The identifier supports tracking; it does not create another folder level.

## File names

Use lowercase kebab-case and describe the content clearly:

- `family-meal-planner-us-letter.pdf`
- `family-meal-planner-a4.pdf`
- `family-meal-planner-instructions.pdf`
- `etsy-listing-image-01-cover.png`
- `instagram-launch-post.png`

Add a version only to working source files when needed, such as `family-meal-planner-source-v03.canva`. Customer deliverables should use clean names without internal version labels.

## Canva product folders

Use the customer-facing product name for the product folder, then use consistent subfolders: Designs, Etsy Shop, Templates, Marketing, and Archive. Add Listing Images and Mockups beneath Etsy Shop.

Create product folders directly beneath **H4HappyLiving → Product**. Do not reuse the archived Organize, Learn, Create, Thrive, or Bundles folders; assign the pillar in product metadata instead.
