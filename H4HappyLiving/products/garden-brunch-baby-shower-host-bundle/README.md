## Customer problem

A baby-shower host wants a polished, cohesive event but does not want to design, organize, and troubleshoot separate invitation, game, sign, and print files.

## Product promise

One calm Canva kit that takes the host from invitation to shower day, with a clear first path and dependable print-and-share guidance.

## Included files

- `requirements/product-brief.md` — approved scope, requirements, acceptance criteria, and validation plan
- `research/reference-listing-analysis.md` — functional analysis of three public reference listings
- `designs/visual-direction-options.md` — original Canva foundation options and selection criteria
- Customer deliverables will be added only after a visual direction is approved and tested.

## Key decisions

- Build a focused host system, not a quantity-led mega-bundle.
- Use only original, non-IP garden-brunch artwork, layouts, copy, and game presentation.
- Keep the invitation and mobile invitation editable in free Canva; disclose every fixed element.
- Make the shortest successful path visible: open, personalize, export, and share or print.
- Target a first-use success moment within about 10 minutes.
- Use Canva templates as structural foundations where practical, then replace generic composition and decoration with an original H4HappyLiving system.
